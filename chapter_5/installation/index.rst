KNOWAGE Installation
########################################################################################################################

The present document illustrates how to install and configure the Knowage suite. There will be described the essential steps to succeed with the standard installation on certified environments, which includes the optional use of CAS as a SSO solution and the use of HTTPS protocol.

.. important::
   **Accessing Knowage**

   After completing the installation and starting Knowage, open
   ``<domain>/knowage-vue`` in your browser. Alternatively, you can use
   ``<domain>/knowage``.

   Replace ``<domain>`` with the base URL of your installation, including
   the protocol (HTTP or HTTPS) and the port, if required.
