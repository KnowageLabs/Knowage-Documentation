Knowage 9.1 documentation

Knowage is an open source analytics and business intelligence suite. Use it to explore datasets, build interactive dashboards, run analytical documents and share the results with your organization.

This manual describes Knowage 9.1.0. Features and menu entries depend on your edition, installed engines and the permissions assigned to your active roles. The instructions use the English interface labels.

Start here

  • Use Knowage: sign in, find a document, select parameters and explore data in the user guide.

  • Build analyses: create datasets, dashboards and other documents in Build analyses with Knowage.

  • Manage the platform: configure data sources, schedules and shared resources in Manage Knowage.

  • Install or upgrade: follow Install and configure Knowage 9.1, including the 9.0 to 9.1 upgrade.

See What’s new in Knowage 9.1 for the changes in this release.
