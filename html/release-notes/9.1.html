What’s new in Knowage 9.1

Knowage 9.1.0 was released on 2 October 2026. The interface and document loading flow have been redesigned. Dashboard and Cockpit are separate document types; each has its own editor and template handling.

Table 1 Changes and where to find them

Area

User-visible changes

Navigation

Updated interface and access to modules. Start with Finding your way around.

Dashboard authoring

Dynamic widget titles, commands to lock or unlock all widgets, and dataset-specific active selections. See Create a Dashboard.

Charts, tables and maps

More category and color settings, dynamic table columns, variable-driven column visibility, alias-aware search, pivot summary controls and a map visualization wizard.

Parameters and QBE

LOV cloning, tree-driver search, multiple searches in parameter dialogs, minimum selectable dates and formatted QBE tooltips. See Analytical Driver, List Of Value and How to build a QBE.

Exports and scheduling

Custom export filenames and worksheet names, improved table PDF output, XLSX export of drill-down charts and combined scheduled PDF, XLSX and HTML outputs. See Scheduler.

Administration

Bulk import of profiled users, user lifecycle improvements and extended role, menu, external-link and portal settings. See User profile and roles and Menu management.

This release also corrects chart rendering, table aggregation, selections, parameter propagation, dataset persistence and cache management, QBE relationships, authentication, MFA, role management and Registry editing.

Upgrading an existing installation

Follow Upgrade Knowage 9.0 to 9.1 to update the application packages and metadata schema together. Keep an existing Cockpit as a Cockpit until you deliberately migrate and validate a copy as a Dashboard.

The 9.1.0 release still distributes BIRT, Jasper, Cockpit, KPI, Meta and QBE engines. Availability in an installation depends on the deployed packages and edition. Use the relevant document guide for each engine.

Release reference

The official 9.1.0 release contains the release notes and application archives. The procedures in this manual target that release rather than the development branch.
