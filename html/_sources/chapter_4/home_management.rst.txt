Home page management
====================

Use **Home Management** to choose the starting page shown to users by role.
Configure a default home for roles without a dedicated setting and override it
for individual roles where required.

1. Open **Home Management** from the authorized management modules.
2. Select the default entry or the role to configure.
3. Choose a home type: default, static page, document, image/URL or dynamic.
4. Set the corresponding page, document, URL or template content.
5. Preview the result where available and save. Test the home page with the
   intended role and its document permissions.

For a dynamic home, use the HTML/CSS editor and insert menu placeholders with
the menu-item picker. Preview the template for the intended role. A document
home requires access to the selected document; choosing it as the starting
page preserves the document's permission checks.

Use **Reset to default** to return to the default configuration.
