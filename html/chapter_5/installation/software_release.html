Get the Knowage 9.1 packages

Download Community Edition archives from the v9.1.0 release. Enterprise Edition customers obtain the corresponding packages and licensed components through their distribution channel.

Use one release consistently across the applications and engines. The 9.1.0 assets include the main applications knowage.war, knowage-api.war and knowage-vue.war, together with the available BIRT, Jasper, Cockpit, KPI, Meta and QBE engine archives. Deploy the engines required by your solution.

Database scripts are in the tagged source tree. Choose the MySQL/MariaDB, PostgreSQL or Oracle directory matching your metadata database. Use creation scripts for a new schema and upgrade scripts for an existing schema. Check database-version compatibility before execution.

For an existing installation, follow Upgrade Knowage 9.0 to 9.1.

License hardware identification

For an Enterprise deployment requiring a stable MAC-based license identifier, the deployment may use this JVM property in setenv.sh:

export JAVA_OPTS="$JAVA_OPTS -Dmac.address.licensing=true"

Agree the license identifier with your distribution channel before changing an existing licensed installation.
