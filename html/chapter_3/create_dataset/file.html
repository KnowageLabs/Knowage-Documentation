File datasets

A File dataset reads a tabular CSV or Excel file.

  1. Create a dataset of type File and upload the source file.

  2. Check the parsing options, including the delimiter, quotation character and date format where applicable.

  3. Preview the parsed rows. Check column names, dates, decimal values and non-ASCII characters before continuing.

  4. Review each column in Metadata, choosing its data type and Attribute or Measure role.

  5. Save and reopen the dataset to verify the result.

When replacing a file used by existing analyses, preserve the expected column names and types or update the dependent documents accordingly.
