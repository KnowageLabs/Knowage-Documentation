QBE datasets

A QBE dataset stores a query built over a published business model. QBE availability depends on the installed engine and edition.

  1. Create a dataset of type QBE.

  2. Select the data source and datamart/business model.

  3. Open the QBE editor, select the fields and configure filters, aggregation and ordering.

  4. Preview the query result and save the query back to the dataset editor.

  5. Review the generated query and column metadata, then save the dataset.

See How to build a QBE for the query editor and How to build a Metamodel for business-model authoring.
