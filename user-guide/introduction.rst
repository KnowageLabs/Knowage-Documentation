Getting started
===============

Your first analysis
-------------------

1. Open the Knowage address supplied by your organization and sign in.
2. Select your working role if prompted. The active roles determine which
   documents, data and commands you can use.
3. Open **Documents Browser**, or choose a document from a configured menu.
4. Search for the document and open it.
5. If a parameter panel appears, fill in the required values and choose
   **Execute**.
6. Explore the result using the filters and interactions provided by its author.

For example, open a sales dashboard, choose a year and a region, then select a
product category in a chart. Related widgets update according to the dataset
associations configured by the author.

Documents, datasets and permissions
-----------------------------------

An **analytical document** is a saved analysis, such as a Dashboard, Cockpit,
report or QBE query. A **dataset** supplies the data used by an
analysis. A **data source** connects Knowage to the underlying system.

Document parameters are selected before execution. Dashboard selections filter
the data while you explore it. Changing a selection and changing a document
parameter can therefore affect the result in different ways.

Use :doc:`user-interface` to find your tools and :doc:`document-execution` to
learn about saved views and exports. Authors can continue with
:doc:`/chapter_3/create_new_dashboard/index`.
