What's new in Knowage 9.1
=========================

Knowage 9.1.0 was released on 2 October 2026. The interface and document loading
flow have been redesigned. Dashboard and Cockpit are separate document types;
each has its own editor and template handling.

.. important:: Enterprise Edition (EE) features

   Features marked **Enterprise Edition (EE)** are reserved for the licensed
   edition. This includes :doc:`AI management </chapter_4/ai_management>` and
   the :doc:`AI assistant </user-guide/ai-assistant>`. Their services and role
   permissions must also be configured.

.. list-table:: Changes and where to find them
   :header-rows: 1
   :widths: 35 65

   * - Area
     - User-visible changes
   * - Navigation
     - Updated interface and access to modules. Start with
       :doc:`/user-guide/user-interface`.
   * - Dashboard authoring
     - Dynamic widget titles, commands to lock or unlock all widgets, and
       dataset-specific active selections. See
       :doc:`/chapter_3/create_new_dashboard/index`.
   * - Charts, tables and maps
     - More category and color settings, dynamic table columns, variable-driven
       column visibility, alias-aware search, pivot summary controls and a map
       visualization wizard.
   * - Parameters and QBE
     - LOV cloning, tree-driver search, multiple searches in parameter dialogs,
       minimum selectable dates and formatted QBE tooltips. See
       :doc:`/chapter_3/security_management/driver`,
       :doc:`/chapter_3/security_management/lov` and
       :doc:`/chapter_3/create_qbe/qbe`.
   * - Exports and scheduling
     - Custom export filenames and worksheet names, improved table PDF output,
       XLSX export of drill-down charts and combined scheduled PDF, XLSX and
       HTML outputs. See :doc:`/chapter_4/schedule`.
   * - Administration
     - Bulk import of profiled users, user lifecycle improvements and extended
       role, menu, external-link and portal settings. See
       :doc:`/chapter_3/security_management/role_user` and
       :doc:`/chapter_3/security_management/menu`.

This release also corrects chart rendering, table aggregation, selections,
parameter propagation, dataset persistence and cache management, QBE
relationships, authentication, MFA, role management and Registry editing.

Upgrading an existing installation
----------------------------------

Follow :doc:`/chapter_5/upgrade/how_upgrade_9_0_to_9_1` to update the application
packages and metadata schema together. Keep an existing Cockpit as a Cockpit
until you deliberately migrate and validate a copy as a Dashboard.

Install the 9.1.0 applications and the engines required for the documents
covered in this manual. Availability depends on the deployed packages and
edition. Use the relevant document guide for each engine.

Release reference
-----------------

The `official 9.1.0 release <https://github.com/KnowageLabs/Knowage-Server/releases/tag/v9.1.0>`_
contains the release notes and application archives. The procedures in this
manual target that release rather than the development branch.
